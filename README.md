# khub.ai

The website of KHUB.ai and Kith, a teachable mind for robots and drones. Served by GitHub Pages at
[khub.ai](https://khub.ai).

English pages are at the top level; Traditional Chinese pages are in `zh-tw/`. Every page has a button that opens the
same page in the other language.

| English | 繁體中文 |
|---|---|
| `index.html` | `zh-tw/index.html` |
| `how-kith-works.html` | `zh-tw/how-kith-works.html` |
| `demonstrations.html` | `zh-tw/demonstrations.html` |
| `about.html` | `zh-tw/about.html` |

Plain HTML and one stylesheet (`styles.css`); no build step. Pictures are in `images/`. The juggling videos are played
from [kaihuchen.github.io/articles/KithIntro](https://kaihuchen.github.io/articles/KithIntro/).

To preview locally, run `python -m http.server 8765` in this folder and open http://localhost:8765/.
